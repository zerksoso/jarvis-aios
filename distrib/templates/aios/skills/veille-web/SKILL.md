# Veille web

Collecte des informations récentes vérifiées, croise les sources et rédige une fiche exploitable.

## Étapes

1. Formuler 2 à 3 requêtes précises et lancer `web.chercher` sur les mots-clés du sujet.
2. Sélectionner les 2 ou 3 sources les plus fiables et lire leur contenu complet via `web.lire`.
3. Croiser les faits et distinguer clairement les annonces vérifiées des estimations ou rumeurs.
4. Rédiger une synthèse structurée (points clés, impacts concrets, liens sources) dans `04-Analytics-Resultats` via `cerveau.ecrire`.
5. Afficher un résumé concis à l'utilisateur ou épingler une carte de veille.
