# Méthode de prospection ciblée

Processus utilisé pour exécuter [[prospection-clients-q4]] sans spam ni dispersion.

## Étapes

1. **Ciblage** : sélectionner des entreprises avec un besoin concret identifié via [[methode-veille-technologique]].
2. **Recherche rapide** : vérifier l'actualité et les signaux récents selon [[lecon-verifier-avant-affirmer]].
3. **Message personnalisé** : rédiger un message court axé sur un problème précis, jamais générique.
4. **Relecture humaine** : validation obligatoire avant tout envoi ([[lecon-ne-jamais-publier-sans-relecture]]).
5. **Suivi** : enregistrer les retours dans [[tableau-suivi-resultats]].
