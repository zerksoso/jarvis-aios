# Principes de décision

Ensemble de critères simples pour arbitrer les priorités décrites dans [[profil-utilisateur]].

## Règles de priorisation

1. **Impact avant agitation** : privilégier les tâches qui font avancer [[jarvis-aios-roadmap]] ou [[prospection-clients-q4]].
2. **Simplicité d'abord** : éviter la sur-ingénierie, comme rappelé dans [[lecon-limiter-complexite-automatisations]].
3. **Preuves vérifiées** : ne jamais conclure sans vérifier les données, conformément à [[lecon-verifier-avant-affirmer]].
4. **Validation humaine** : toute communication externe ou action irréversible passe par relecture ([[lecon-ne-jamais-publier-sans-relecture]]).
